# PoE Flip Overlay beta 0.2

Technical version: `0.1.0-beta.2`.

- Start with an active, interactive window instead of passive click-through.
- Keep the Windows title bar, resize borders, taskbar entry and minimize/maximize/close controls.
- Enable click-through explicitly with the visible button; show recovery shortcuts and the current input mode beside it.
- Keep recovery hotkeys, stable installer AppId, user-data paths and trading calculations unchanged.

Windows installer, portable and native window acceptance results are recorded with this release's build evidence. Unit tests alone do not certify game interaction, clean-VM compatibility, DPI or frame-time budgets.
